# REGLA PERSONALIZADA DE USUARIO: MODO LIGHT OBLIGATORIO (ANTI-DARK MODE)

- **QUEDA ESTRICTAMENTE PROHIBIDO USAR FONDOS OSCUROS / DARK THEME.**
- El usuario detesta los temas oscuros (`#000000`, `#0B0C0E`, `#141514`, grises oscuros, etc.).
- Toda la aplicación y todos los componentes deben diseñarse SIEMPRE en **Light Mode**:
  - Fondo oficial Claude/Anthropic: Warm Cream / Parchment (`#FAF9F5` o `#F7F5F0`).
  - Superficies de tarjetas: Blanco puro (`#FFFFFF`) o crema sutil (`#F0EFEA`).
  - Bordes: Sutiles, cálidos y finos (`#E5E3D8` o `#E2E0D8`).
  - Textos: Carbón oscuro nítido (`#1A1915` o `#2D2B28`) y gris cálido secundario (`#706E66`).
  - Acentos: Terracota Claude (`#D97043` / `#CC6B3D`), Verde Salvia (`#6E8B68`), Azul Pacífico (`#4A8B99`) y Oro Costero (`#D4A359`).
- Enfoque Mobile-First real: centrado con ancho de teléfono elegante y márgenes armónicos.
